# UI design handoff

`tt-platform-handoff/` is the approved design handoff (HANDOFF.md, `design/*.dc.html` mocks, `styles/` tokens).
The mocks are reference, not production code; their sample data is fictional. Staff routes map `/x` to `/admin/x`
(see CLAUDE.md "Repo notes (UI handoff, step 1)"). The logo files and the Delivery Note legal text from the later
handoff version live in `public/` and the kit content respectively.
